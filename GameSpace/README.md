# Game Space — Alya AI Service
Game booster Android 8 – 17+ (minSdk 26), landscape, panel overlay dari kanan sampai tengah layar.

Build: buka folder ini di Android Studio (Ladybug atau lebih baru) → Sync → Build > Build APK(s).
(Gradle wrapper jar akan dibuat otomatis oleh Android Studio.)

Pakai:
1. Buka app → aktifkan izin (overlay, akses penggunaan, notifikasi), opsional Shizuku.
2. Centang game → "Mulai Alya AI Service".
3. Buka game → handle ungu muncul di tepi kanan → tap / geser kiri → panel slide dari kanan (setengah layar).
